# Signal Definitions

## Flood Alert

Triggered when water level exceeds threshold.

Severity:
CRITICAL

Source:
Water Sensors

Action:
Create Telemetry Event

---

## Traffic Congestion

Triggered when traffic density exceeds threshold.

Severity:
HIGH

Source:
Traffic Cameras

Action:
Create Telemetry Event

---

## Power Failure

Triggered when grid reports outage.

Severity:
MEDIUM

Source:
Power Grid

Action:
Create Telemetry Event
