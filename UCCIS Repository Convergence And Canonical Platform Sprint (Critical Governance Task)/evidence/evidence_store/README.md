# Evidence Store

Store all collected evidence files here.

Structure:

evidence_store/
│
├── runtime_logs/
├── api_proofs/
├── screenshots/
├── trace_records/
└── review_packets/

Naming Convention:

TRACE-ID_TIMESTAMP_TYPE.ext

Example:

TRACE-1001_20260618_RUNTIME.log
TRACE-1001_20260618_SCREENSHOT.png
TRACE-1001_20260618_API.json
